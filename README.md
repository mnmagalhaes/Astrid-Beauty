# 🌟 Astrid Beauty — Salão de Beleza & Estética

Website oficial do **Astrid Beauty** (fundado em 27/04/2025). Desenvolvido com interface moderna, elegante e responsiva em tons de dourado e cinza, focada na melhor experiência para o cliente.

---

## ✨ Funcionalidades

- **Hero Interativo:** Banner com slider de fotos e transições suaves.
- **Tabela de Serviços 3D:** Exibição organizada com efeitos interativos ao passar o mouse (*hover*).
- **Agendamento Online:** Formulário intuitivo com seleção de horários.
- **Contato & Localização:** Cards interativos com links para mapa e informações.
- **Totalmente Responsivo:** Perfeito para celulares, tablets e computadores.

---

## 🛠️ Tecnologias

- **HTML5** (Semântico)
- **CSS3** (Flexbox, CSS Grid, Efeitos 3D, Variáveis CSS)
- **JavaScript** (Vanilla)
- **Google Fonts** (*Cinzel Decorative* & *Poppins*)
